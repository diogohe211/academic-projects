# Tree Insertion Benchmarks

Compares insertion time and rotation counts for AVL trees, red-black trees and treaps on ordered and shuffled datasets with repeated keys.

## Requirements

Python 3. Uses only the standard library.

## Run

```sh
python Projeto2.py
```

For a first run, reduce the dataset sizes in the main block.

## Project notes

Duplicate keys are skipped. A generic binary tree is also implemented, with its benchmark disabled. The default run generates one million elements.
