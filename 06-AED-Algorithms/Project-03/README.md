# Sorting Benchmarks

Compares Insertion Sort, Heap Sort and randomised Quick Sort on ascending, descending and shuffled data.

## Requirements

Python 3. Uses only the standard library.

## Run

```sh
python proj3.py
```

For a first run, reduce the dataset sizes in the main block.

## Project notes

The default sizes reach one million elements. Insertion Sort can take a long time. Insertion Sort and Heap Sort mutate their list; Quick Sort returns a new list.
