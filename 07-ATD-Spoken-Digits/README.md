# Spoken Digit Analysis

MATLAB Live Script exploring audio preprocessing, time-domain and spectral features, digit classification and time-frequency analysis across four coursework milestones.

## Requirements

MATLAB with Live Editor and the signal-processing and wavelet functions used by the script.

## Run

Open Projeto.mlx in MATLAB. Set its folder as the current directory, restore the audio dataset under data and review the referenced MAT files. Execute the sections in order so later sections can use the data prepared earlier.

## Project notes

Several sections load dados_audio.mat and other intermediate data. The source folder currently contains the Live Script; the dataset and intermediate MAT files need to be supplied separately.
